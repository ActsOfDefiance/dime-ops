---
name: Licensing policy
description: GPLv3 for all repos except art/images which need a separate license
type: project
---

All repos use GPLv3 except art assets.

**Why:** Open source from day one, but art (generated images, graphics) needs different licensing terms.

**How to apply:** When adding LICENSE files to new repos, use GPLv3. Do not apply GPLv3 to image/art output.
