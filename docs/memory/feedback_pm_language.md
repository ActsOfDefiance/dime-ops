---
name: Use consensus language in process docs
description: Never use individual names in playbook/process patterns — use "we" language for open source consensus-driven project
type: feedback
---

Process docs, playbook entries, and PM agent patterns must use "we" language, not individual names. This is an open source project — decisions and preferences are consensus-driven.

**Why:** Open source from day one. Patterns belong to the project, not to individuals.

**How to apply:** Write "We prefer X" not "Vance prefers X". Write "The team decided Y" not "User decided Y". Applies to playbook.md, docs/process/*, and any learned patterns.
