# Definition of Done

What "done" means for each issue type.

## Feature

- [ ] Implementation complete
- [ ] Tests pass with 90%+ coverage (where applicable)
- [ ] Quality gates clean (ruff, pyright, ESLint, etc.)
- [ ] PR created, reviewed, and merged
- [ ] GitHub issue closed

## Bug

- [ ] Root cause identified
- [ ] Fix implemented
- [ ] Regression test added
- [ ] PR created, reviewed, and merged
- [ ] GitHub issue closed

## Decision

- [ ] Options explored with trade-offs
- [ ] Decision made with rationale recorded
- [ ] Moved from `open-decisions.md` to `settled-decisions.md`
- [ ] Dependent issues unblocked

## Epic

- [ ] All sub-issues meet their Definition of Done
- [ ] Epic-level DoD checklist (in the epic file) passes
- [ ] No open blockers remain

## Maintenance

- [ ] Change implemented
- [ ] Existing tests still pass
- [ ] PR created, reviewed, and merged

## Security

- [ ] Vulnerability addressed
- [ ] Secrets rotated (if applicable)
- [ ] Git history clean (if secrets were exposed)
- [ ] Preventive measure in place (hook, gitignore, etc.)
