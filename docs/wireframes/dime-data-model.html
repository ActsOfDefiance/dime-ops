Key relationships
article.project_id→project.id(many articles per project)
article.current_draft_id→article_version.id(current working version)
article_version.article_id→article.id(full version history)
image_slot.article_id→article.id(one slot per image type)
image_slot.selected_variant_id→image_variant.id(chosen final image)
image_variant.slot_id→image_slot.id(all generated variants)
publish_event.article_version_id→article_version.id(which version was published)
user.role_id→role.id(one role per user, roles are extensible)
