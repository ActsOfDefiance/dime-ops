Content Pipeline State Machine

Each article moves through these states. Human checkpoints shown in amber. Agent work in blue. Terminal states in green/red.

Agent work (background)
Human checkpoint (blocks pipeline)
Terminal: success
Waiting
queued
Topic submitted (title, brief, tags, target project). Sits in queue until a worker picks it up.
human: submit topic system: assign priority
researching
ResearchAgent gathers sources, facts, quotes, citations. Produces structured research notes in markdown. Long-running — progress streamed to UI.
agent: web research agent: source verification output: research.md
research_review ✋
Human reviews research notes in the right pane. Can approve, reject, or edit inline. Can chat: "find more on X", "remove this source", "add context about Y". Dime re-researches if asked.
approve → writing edit inline chat: re-research reject → queued
writing
WriterAgent composes the article from approved research. Produces both TLDR and Research sections in the compendium format. Streamed to UI as it writes.
agent: compose TLDR agent: compose research section output: article draft.md
draft_review ✋
Human reads the full draft in the right pane. Rich text editor — direct editing. Chat interface for guided rewrites: "shorten the intro", "add a section on X", "change the tone".
approve → art_briefing edit inline (rich text) chat: rewrite sections reject → writing
⚡ Art briefing runs in parallel with draft_review if desired — the art brief can be generated while the human edits the draft.
art_briefing
ArtDirectorAgent reads approved draft and project style guide. Generates image prompts for each required asset (hero, thumbnail, etc.) with dimensions and style tokens from the style guide config.
agent: generate prompts consults: style guide config output: art_brief.md
art_review ✋
Human reviews art brief and prompts. Edits prompts, changes style direction, adjusts crop/size requirements. Right pane shows prompt editor with style guide constraints visible.
approve → art_generating edit prompts chat: adjust direction
art_generating
Calls Imagen (or configured provider) with approved prompts. Generates multiple variants per asset. Results appear in the right pane's image studio — the human can iterate here without leaving this state.
agent: call Imagen API human: compare variants human: iterate prompts human: select finals output: art/ assets
final_review ✋
Complete package: article + all selected images. Human sees the full preview — how it will look published. Can still edit text or swap images. Final approval gates the publish queue.
approve → approved last-minute edits reject → specific stage
approved
Canonical markdown written to compendium/. Art written to art/. Sits in publish queue awaiting scheduling or manual trigger.
compendium/ written art/ written human: schedule or publish now
publishing
PublishingAdapter receives signal. Copies files to target, triggers build, records publish event (timestamp, target, adapter version) back to PostgreSQL.
signal: adapter.publish() AstroAdapter: copy + build
published ✓
Article live. Publish event recorded. Article can be updated (re-enters draft_review) or unpublished. Version history maintained in PostgreSQL.
audit log entry can update → draft_review can unpublish → approved
